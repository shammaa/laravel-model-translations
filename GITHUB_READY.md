# Release Steps for laravel-model-translations

1.  **Initialize Git**:
    ```bash
    git init
    git add .
    git commit -m "Initial release of Smart Model Translations"
    ```

2.  **Create Github Repository**:
    Create a repo named `laravel-model-translations` on GitHub.

3.  **Push to GitHub**:
    ```bash
    git remote add origin https://github.com/shammaa/laravel-model-translations.git
    git push -u origin main
    ```

4.  **Tag First Version**:
    ```bash
    git tag v1.0.0
    git push origin v1.0.0
    ```

5.  **Submit to Packagist**:
    Go to packagist.org and submit the URL.
